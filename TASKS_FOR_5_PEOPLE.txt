ПЛАН РАБОТЫ ДЛЯ 5 РАЗРАБОТЧИКОВ
================================

Цель проекта:
Сделать стабильную учебную платформу StudyAI для загрузки документов,
генерации вопросов, тестирования, карточек и аналитики.

ВАЖНЫЕ ПРАВИЛА
---------------

1. Не работать напрямую в main.
2. Каждый разработчик создаёт свою ветку:

   git checkout main
   git pull
   git checkout -b feature/название-задачи

3. Перед отправкой изменений выполнить:

   python -m py_compile app.py web_app.py

4. Отправить ветку:

   git add .
   git commit -m "Описание изменения"
   git push -u origin feature/название-задачи

5. Создать Pull Request в main.
6. Не объединять Pull Request без проверки CI и ревью другого разработчика.
7. Не добавлять .env, API-ключи, пароли и личные документы.
8. Не переписывать историю main через force push.


ЧЕЛОВЕК 1 — BACKEND И БАЗА ДАННЫХ
----------------------------------

Приоритет: P0.

Задачи:

1. Перенести проекты из временного словаря projects в постоянное хранилище.
2. Создать таблицы для пользователей, документов, вопросов, попыток и карточек.
3. Реализовать создание, получение, изменение и удаление проекта.
4. Добавить список сохранённых документов и загрузку проекта после перезапуска.
5. Исправить сохранение вопросов, чтобы повторное сохранение не создавало дубликаты.
6. Добавить миграции базы данных.
7. Подготовить резервное копирование базы.
8. Проверить работу после перезапуска Flask.

Файлы:
- web_app.py
- app.py
- questionforge.sqlite3

Готово, если:
- данные не исчезают после перезапуска;
- вопросы и попытки загружаются из базы;
- нет дубликатов при повторном сохранении;
- API возвращает понятные ошибки.

10. Проверить тесты с неправильными, пустыми и подменёнными ответами.

Файлы:
- web_app.py

Готово, если:
