# StudyAI

AI Learning Platform для анализа учебных материалов, генерации вопросов, мини-тестов и повторения тем.

## Запуск

```powershell
cd "C:\Users\Шерхан\Desktop\Шерхан\Проекты\Бизнес проект\question_generator_pro"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python web_app.py
```

Откройте в браузере: `http://127.0.0.1:5000`

`web_app.py` — основной интерфейс StudyAI с Dashboard, AI Analysis, Smart Quiz, Flashcards и Learning Analytics. `app.py` оставлен как запасной Streamlit-вариант.

Для генерации через OpenAI создайте `.env` на основе `.env.example` и укажите `OPENAI_API_KEY`.
Без ключа приложение работает в демонстрационном режиме: темы и вопросы создаются локально по загруженному тексту.

## Возможности

- загрузка PDF и TXT;
- извлечение текста с номерами страниц;
- автоматическое определение тем;
- пять уровней сложности;
- тестовые и открытые вопросы;
- ответы, объяснения и источник;
- редактирование, удаление и поиск;
- SQLite-хранилище;
- проверка качества и повторов;
- генерация набора сразу по всем пяти уровням;
- проверка открытых ответов;
- экспорт JSON и CSV.
